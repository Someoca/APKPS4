# Plano de backend PS4

Antes de implementar o backend:

1. Confirmar APIs efetivamente disponíveis na toolchain instalada.
2. Identificar bibliotecas e headers oficiais utilizáveis.
3. Definir inicialização, alocação e apresentação gráfica.
4. Validar um programa mínimo no hardware.
5. Só então integrar o pipeline de imagem.

Não inventar símbolos GNM/GNMX nem assumir acesso ao framebuffer de
processos de jogos externos.
